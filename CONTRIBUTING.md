# Contributing to Crypto-Things

Thank you for your interest in contributing to **Crypto-Things**! We welcome contributions that improve the educational value, fix bugs, or add new examples/tutorials on cryptographic ledgers.

## How to Contribute

1. **Fork the Repo**: Click "Fork" on GitHub to create your copy.
2. **Clone Locally**: `git clone https://github.com/YOUR_USERNAME/Crypto-Things.git`
3. **Create a Branch**: `git checkout -b feature/your-feature-name` (e.g., `add-rsa-example`).
4. **Make Changes**: Follow the style guidelines below. Test with the GitHub Actions workflow.
5. **Commit**: Use descriptive messages: `git commit -m "Add RSA signature example with demo"`.
6. **Push**: `git push origin feature/your-feature-name`
7. **Open a Pull Request (PR)**: Link to the issue (if any) and describe changes.

## Style Guidelines
- **Code**: Use Python 3.8+; follow PEP 8. Add docstrings to functions.
- **Docs**: Markdown files in `/docs`—use tables, code blocks, and links.
- **Examples**: Runnable scripts in `/examples` with comments and output examples.
- **Exercises**: Challenges in `/exercises` with solutions in collapsible sections.

## Development Workflow
- Run tests: The `.github/workflows/test-examples.yml` will auto-run on PRs.
- Preview docs: Use a Markdown viewer or GitHub Pages.

## Reporting Bugs or Suggesting Features
- Open an [Issue](https://github.com/DersonProductions/Crypto-Things/issues/new).
- Use templates for bugs or features.

## Code of Conduct
Please review our [Code of Conduct](CODE_OF_CONDUCT.md) for interactions.

## Questions?
Ping us in an issue or discuss in the repo's Discussions (enable if needed).

Happy contributing! 🔒
