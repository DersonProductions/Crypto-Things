# Security Policy

## Reporting a Vulnerability

We take security seriously! If you discover a security issue in Crypto-Things (e.g., in code examples or docs), please report it responsibly.

### How to Report
1. **Email**: Send details to [security@dersonnproductions.us].
2. **What to Include**:
   - Description of the vulnerability.
   - Steps to reproduce.
   - Impact (e.g., affects hashing integrity?).
   - Your contact info (optional, for follow-up).
3. **Do Not**:
   - Open a public issue/PR.
   - Disclose publicly until fixed.

We aim to acknowledge reports within 48 hours and fix critical issues promptly.

### Supported Versions
- Active: Main branch (all examples/docs).
- No end-of-life versions (as this is an educational repo).

### Disclosure
We'll patch and release fixes, then disclose publicly (e.g., via CHANGELOG.md).

Thanks for helping keep crypto education secure! 🔐
